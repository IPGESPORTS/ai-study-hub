# AI Study Hub

En personlig studieplattform byggd med Next.js, React och TypeScript.

## Kom igång

1. Installera Node.js (LTS).
2. Installera beroenden med `npm install`.
3. Starta utvecklingsservern med `npm run dev`.
4. Öppna http://localhost:3000.

## Nuvarande status

Den första versionen innehåller en responsiv dashboard-prototyp med navigation, ämneskort, studiestatistik, veckomål och en interaktiv att-göra-lista.

## Planerade moduler

- Ämnen och kursmaterial
- Dokumentuppladdning och AI-analys
- Anteckningar kopplade till dokument och ämnen
- Flashcards med spaced repetition
- Quiz och provträning
- Studieplanering och kalender
- Statistik över framsteg och kunskapsluckor
- AI-studiecoach integrerad i hela arbetsflödet

## Teknik

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

Backend, autentisering och datalagring kopplas in i nästa utvecklingssteg.
